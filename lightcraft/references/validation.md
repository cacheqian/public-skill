## 已执行：独立 Claude Code 使用演练

使用本机 Claude Code 读取此 Skill，在另一个独立 Synthetic 演示会话中完成任务；没有接入用户当前窗口。测试提示给出任务与材料，没有提供预期参数或答案。

- **实际自然修图与交付**：观察暖色日落图，保留暖光和山体剪影，调整 contrast/highlights/shadows，读回并比较前后预览；导出并重新打开 2048×1365 的 sRGB JPEG。主审另行查看前后图及成品，确认文件可解码且包含 sRGB ICC。本项仅支持合成图上的使用流程，不证明真实日落或人像效果。
- **额外接口核对**：检查 `develop.auto` 的覆盖范围，以及同时传 values/settings 的两步撤销行为；完成后恢复测试状态。
- **仅推演的风格任务**：面对没有参考的“精确 Portra 400”和输入契约未知的 S-Log3 LUT，区分视觉近似与精确复现，不直接承诺兼容。没有实际加载 LUT 或验证胶片响应。
- **仅推演的批量任务**：对室内暖灯与室外蓝调、含已有人工编辑的混合照片，提出分组、代表图/边界图试点和限制复制字段。没有用真实整组照片做审美验收。

演练发现的操作缺口已补入：Auto Sync 的传播与切换语义、明确的同步组名称、headless 细节检查限制，以及 HDR 的 SDR/HDR 评价边界。LUT 最少需补充的信息及混合光分组判断也已明确。

补充后另开独立演示会话做了两项实际检查：开启 Auto Sync 且原先多选时，带单个 ID 的 `set_develop` 将操作隔离为单图，另一图设置不变；显式只复制/粘贴 `colorGrading` 和 `grain` 时，返回 changed=1，目标的其他所有设置组（含 WB、曝光和既有对比度）保持原样。测试后两图完整设置恢复到基线。本项验证范围控制与字段选择，不构成真实整组审美验证。

另启 `mcp --demo --compact` 内存演示库，预先创建一张已有蒙版，再测试新 radial、局部 exposure、显式 visible false/true、指定 mask 删除以及 master 点曲线写入。

- 局部修改后 PNG 像素实际变化，检查的角落区域像素未变；全局 light 和已有蒙版保持原样。
- 显式关闭新蒙版时 PNG 恢复到添加前，重新开启后回到修改结果；仅删除新 mask 后完整设置等于创建前。

- 完整点列写入 master 曲线后读回正确、渲染像素变化；其他曲线字段与蒙版保留。
- 测试结束后完整还原隔离会话基线，另一个合成照片设置不变；主审实际查看局部修改前后的演示预览。

此检查通过的是已列命令与范围控制，不验证人物识别、头发边缘、混合光修色或真实局部塑光审美。题材方法和试调步长仍是条件化建议。

## 后续真实照片案例

下列场景是 **待新增或扩大验证的案例设计**；已有两张夜景 JPEG 只提供有限覆盖，不构成完整作品集：

| 场景 | 需要的材料 | 主要验收点 |
|---|---|---|
| 逆光人像自然调整 | 有使用授权的原图、目标氛围；最好有 RAW 与 JPEG 对照 | 脸部可读性提高，现场光保留，肤色可信，背景不过度变亮，面部无明显噪声/光晕 |
| 夜景/蓝调 | 有暗部层次的原图及用户希望保留的黑位 | 保留夜景层次和光源颜色，不把夜景拉成白天；高 ISO 细节另看 100% |
| 参考图风格迁移 | 目标原图、可查看参考图、所需相似维度 | 比较明暗/冷暖/色彩关系，区分光线差异，不承诺精确胶片响应 |
| 混合光整组 | 同组不同位置/曝光的真实图，明确照片范围 | 先分组，代表图和边界图通过，局部色偏单独处理，异常图不被统一参数掩盖 |
| 高位深/色彩交付 | 要求的格式、输出空间、ICC 与查看条件 | 文件可解码、位深与 profile 相符；同一色彩管理条件下比较预览和导出 |
