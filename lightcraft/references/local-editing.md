# 局部处理：选择范围、塑光与检查边缘

适用于全局调整总会伤害其他区域的情况。先选作用范围，再选择明暗/色彩控件；不为了“高级修图”强行增加蒙版。下述命令形状依据 LightCraft 0.13.0，使用前仍需实时发现并核对。

## 1. 选择什么范围

| 问题形状 | 候选选择 | 特别检查 |
|---|---|---|
| 天空到地面的宽缓亮度变化 | linear 渐变 | 渐变会穿过高楼/树梢；必要时与其他选择交集或减去主体 |
| 一张脸、一处产品、一片前景的宽柔塑光 | radial 或柔边 brush | radial 不识别物体；脸外墙面、发丝和衣领容易一起被提亮 |
| 不规则物体或分散区域 | brush，或有能力时的 object/subject | 笔刷边缘与真实光照过渡是否一致；自动选择必须实际看边缘 |
| 限定已有区域里的某段亮度/颜色 | luminanceRange/colorRange 与空间选择 intersect | 范围筛选会随输入/曝光或处理条件变化，不等于固定物体区域 |

蒙版 ID 与照片 ID 不同。`command_run` 的外层 `id` 是命令字符串，`params.id` 在 mask 命令里是 mask ID；目标照片靠活动选择确定。先明确单选照片，防止 Auto Sync 扩大范围。

## 2. 最小可执行流程

1. 保存原有 masks 及本轮涉及设置；若照片已裁剪/旋转/透视，先确认坐标对应关系。LightCraft shape 的位置在带方向的源图归一化坐标中定义；radial 的 rx/ry 则按源图长边归一化，不能分别当宽/高百分比。不能直接把裁剪后屏幕坐标当源图坐标。难以映射时优先使用可检查的 UI 选区，不猜对象位置。
2. 发现 `mask.add` / `mask.adjust` / `mask.visible` / 必要的 `mask.addComponent`。创建新蒙版后读取 `get_develop.masks`，拿实际返回的 `activeMask` 和对应对象，核对 shape、visible 和 adjust。
3. **新蒙版可能继承上次同类型使用的效果**，并不保证创建时所有调整均为零。先确认它实际带了哪些设置；需要中性起点时，仅清理本轮新蒙版的继承效果，不改用户旧蒙版。
4. 在可用 UI 叠加显示或渲染对比中确认覆盖。没有叠加查看能力时，用低强度候选的开关对比检查，标明边缘检查的分辨率限制。参数正确不等于选择正确。
5. 用 `mask.adjust` 只传本轮要改变的局部字段，读回并渲染。目标只是提脸，就先试局部曝光；需要兼顾亮斑时再评估局部 highlights，不一次加入所有质感/色彩设置。
6. 明确设置 `mask.visible {id, visible:false/true}` 作 A/B，恢复正确最终可见状态。省略 visible 会切换，不能当成查询。不要在开关时抹掉用户原本隐藏的蒙版状态。
7. 失败先降低量/扩大柔和过渡，或修正选择；仍无收益时仅删除本轮新建的那个蒙版，或精确还原本轮对旧蒙版的修改。不要用 `mask.deleteAll` 恢复本轮。

参数示意（位置和数值不适用于任意照片，先确认实际坐标与默认效果）：

```json
{"id":"mask.add","params":{"kind":"radial","center":[0.5,0.5],"rx":0.2,"ry":0.15,"feather":70,"name":"本轮局部提亮"}}
```

拿到实际 `activeMask` 后，调用形状为：

```json
{"id":"mask.adjust","params":{"id":3,"values":{"exposure":0.15}}}
```

3 只是演示 mask ID。局部 `exposure` 是该蒙版的设置绝对值；已有局部曝光 0.4 时试增 0.15，应写 0.55。不要把 `light.exposure` 控件 ID 填进局部 values，也不要把局部 temp 当 Kelvin。

## 3. 已有蒙版的叠加与无叠加视图时的检查

“保留旧蒙版”包含两件事：旧对象的设置不被改写，以及新增处理后的整体外观仍符合其原意。0.13.0 CPU 管线会按覆盖 alpha 加权累积多个蒙版的 exposure 等局部项，所以两个覆盖同一张脸的提亮蒙版会叠加效果；不能因旧蒙版字段未变就说它的观感没有变化。局部着色 `color_hue/color_sat` 还有后续有效项的选择行为，不把所有局部效果都当作相同的相加规则。具体依据见 [来源补充](sources.md#本轮新增知识的依据)。

新建前先检查旧蒙版是否已经覆盖问题区域。明确需要保留旧设置时，可以新增较弱的补充层，但要对“旧层保留、新层关闭/开启”的实际渲染比较；不要随意重排蒙版、重复覆盖相同效果，或修改旧层来抵消新层。旧层原本隐藏时保持其隐藏状态。

没有可用叠加视图时：先在当前渲染上标出目标与必须保护的参照区，读取完整 crop/方向/几何状态，确认源图位置映射后再创建候选；分别查看全图和边缘局部，显式关闭/开启本轮蒙版，检查参照区是否发生不希望的变化。位置或边界仍无法可靠确认时，降低范围结论的置信度，优先选能确认的宽柔区域；不能可靠隔离的局部效果暂不执行并说明具体缺少的定位能力。低分辨率 A/B 可以发现大范围泄漏，不能证明细发丝边缘精确。

## 4. 怎样判断局部塑光是否自然

- **整体看方向**：明暗变化符合原有主光、遮挡和体积；只为了可读性提亮，不把背光面调得比主光面更亮。
- **边缘看融合**：发丝、桥索、树枝、天际线、高反差边缘不能有亮圈/暗圈。软蒙版不等于边缘自动正确，过宽羽化也会漏到背景。
- **内部看层次**：局部阴影和纹理仍有差异，提亮后肤色不蜡白、建筑不平板；暗部噪声有必要时另处理。
- **切换看收益**：关闭时能看出目标问题，开启时该问题改善且背景基本保持合理。若只有边界在“浮动”，优先修蒙版而非加强数值。

混合光的局部修色见 [调色实践](color-practice.md#4-混合光确定主光再处理次要光区)。对同组照片复制蒙版前须重新确认位置、姿态和裁剪；同机位也不保证对象相同。

## 5. 能力与验证边界

普通 sky/subject/background 可能使用源图分割信息或启发式，不保证精确识别；object/prompt 需要相应模型或已存分割。返回 pending 时，等到目标蒙版真实存在并可渲染再调，不盲目重建。模型缺失时，任务适合就改用明确的手工选择；不能以“做局部处理”为由自行下载模型。
