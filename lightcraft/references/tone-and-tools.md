# 明暗问题：怎样选择控件

在“看得见问题，但不知道该用哪个工具”时读本页。这里是结合 LightCraft 0.13.0 管线的工作判断；试调幅度属于建议，不是已验证的跨图配方。局部操作见 [局部处理](local-editing.md)，色彩连带变化见 [调色实践](color-practice.md)。

## 1. 先区分三种问题

- **整体位置不合适**：主体、中间调及大部分画面都偏暗/偏亮，才优先考虑整体曝光。
- **亮度分布不合适**：整体位置合适，但亮部太抢或暗部难辨，先考虑 highlights/shadows、白黑端或曲线。
- **空间位置不合适**：同样明度的区域需要不同处理，例如脸要亮而身后墙不用亮，考虑蒙版。全局明度或色相选择不能识别“这一个人”。

看主体、背景和重要高光三个参照区。若改善一个区域总会伤害另一个区域，往往应缩小作用范围，而非再叠一个反方向的全局滑杆。夜景里的黑色、剪影、雾景的低反差都可能是目标的一部分。

## 2. 工具之间的实际区别

| 工具 | 适合的现象与试法 | 不合适的信号 |
|---|---|---|
| `light.exposure` | 整体亮度位置有问题。改变后同时看主体、中间调和重要高光；已有编辑上计算目标绝对值 | 只想救脸却把窗外/天空推亮，或夜色消失：转局部，不靠全局减高光无限抵消 |
| `light.shadows/highlights` | 暗/亮区域分布有问题。先调一侧，检查局部反差和颜色，再决定另一侧 | 暗部像蒙灰、亮部像灰贴纸、轮廓有光晕：减幅或分区；降低高光不能生成源文件没有的纹理 |
| `light.whites/blacks` | 中间调已合适，但明暗端缺乏支点；用来整理端部关系 | 调整后衣纹、毛发、夜景建筑层次成块消失，或暗部浮灰：回退。不为了直方图碰到两端而调整 |
| `light.contrast` | 整体层次分离不足，可接受同时改变多个明度区 | 主体只需提亮，或高光已很紧张：优先其他工具；对比度不是单纯锐化 |
| 参数曲线 `curve.*` | 需要比端部控制更细的明度分区，或整理已有曲线塑形 | 已有点曲线作用不清时先不要叠加。调后同时检查颜色、渐变和中间调 |
| 点曲线 `develop.curve` | 明确要建立某段斜率/柔化高光/塑造黑位，且能保存和读回完整点列 | 为“胶片感”直接套大 S 或任意抬黑；邻近点太密、局部反向、端部过平，会产生反差异常或层次压缩 |
| `effects.clarity/texture` | 明暗位置已合适，仍需调整局部反差或纹理观感 | 原片已锐化、有噪点、肤质发脏、边缘亮圈：不要继续加；缩图显得清楚不代表细节更好 |
| `effects.dehaze` | 雾气/散射让远景层次不足，且目标确实需要更清楚的空气感 | 晨雾/逆光氛围被破坏、天空过深或色彩脏：缩小幅度或只处理相关区域 |
| 局部蒙版 | 同一明度的不同物体需要不同处理；只改善主体或某光区 | 蒙版边缘、遮挡关系和过渡无法做好时，降低强度或换更宽柔的作用区域 |

这些是职责区分，不是软件之间的数值映射。LightCraft 的曝光、高光/阴影、tone map、输出点曲线位于不同阶段；不能假定调整结果互相等价。曲线的 x/y 在 0…1 内表示本阶段输入/输出，不是相机曝光 EV。

## 3. 三种容易混淆的选择

### “画面偏暗”

1. 先看明亮主体/中性参照是否也偏暗。若主要是背景黑、灯光正常，不能直接判定全图欠曝。
2. 若大部分区域都需要移动，试少量曝光；若主体改善而天空/灯光变差，就缩小曝光或改为局部。
3. 若只想增加暗部可读性，试 shadows；检查暗部内部差异是否还在，不将所有暗部抬到相似灰度。
4. 若只是一张脸、一个产品或桥下区域，明确空间范围后用蒙版。保留遮挡、方向光和必要阴影。

### “画面不通透”

依次排查：黑位抬高的已有风格、整体对比不足、真实雾气、局部纹理、输入预览/压缩。分别选对应手段；不要同时加对比、去雾、清晰度和锐化后再猜哪一步有效。远处比近处低反差可能符合空气透视，全部拉成一样清楚会削弱空间感。

### “主体不突出”

先判断亮度分离、颜色竞争、局部反差、构图哪一项最影响观看。可以提亮主体，也可以温和压低抢眼背景、降低无关颜色彩度或适度裁剪。不要每次都增加整图曝光和暗角。构图调整要保留任务需要的内容；透视修正后重新检查裁边和比例。

## 4. 怎样试调，而不是背数字

- 没有可靠起点时，可从本轮基线试 **曝光增减 0.1～0.25 EV**，或单个 -100…100 控件增减 **3～8 个单位**，观察响应再决定。这是小步观察策略，不是最终效果目标；严重问题可能需要更大幅度，已有强编辑则可能需更小幅度。
- `values` 写绝对值：基线曝光为 0.7，本轮想试 +0.15，应写 0.85。每一轮都从当前已读回值计算，避免误写成 0.15。
- 选择一项主要假设；只在确有耦合时联动少数控件。保留相关旧值，失败就还原该轮，不能用另一个全局效果遮住失败。
- 不默认要求零均值、直方图铺满、固定肤色亮度或固定 K 值。到达预期视觉关系即停；候选之间无法稳定判断时保留较少副作用的一版，说明取舍。

## 5. 细节处理的顺序

先在目标明暗下看原像素局部，再判断噪声/压缩/失焦/锐化痕迹。降噪后看毛发、文字、织物和低反差纹理，锐化后看高反差轮廓；有水彩感或亮边就减弱。已处理手机 JPEG 可能已有强锐化和降噪，不按 RAW 的思路再叠一遍。最后在交付尺寸看一次，判断细节处理是否仍有必要。
